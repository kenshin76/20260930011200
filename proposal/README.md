## 내용 동일성

**모든 수치의 단일 출처는 `제안서.md` 입니다.** 웹은 문장을 요약·재배열했지만 숫자는 바꾸지 않았습니다.
`../verify_web.py` 가 제안서.md 를 직접 읽어 아래를 확인합니다 (기대값 하드코딩 없음).

- 제안서의 표 28개 ↔ 웹의 같은 표(`data-md`) — 행 수와 행별 숫자 대조
- 웹에 보이는 숫자 중 제안서 어디에도 없는 숫자 0건
- 핵심 문구 60여 개 존재 여부
- 합계·비율·참여율·MM·가동률·간트 위치·게이트 위치·막대 폭·카운터 초기값 재계산

```
cd submissions/2026093001
python3 verify_web.py 제안서.md proposal/index.html
```

제안서.md 를 고친 뒤 이 스크립트를 돌리면 웹에 반영해야 할 곳이 행 단위로 나옵니다.

## 배포 (GitHub Pages)

이 폴더를 저장소에 올리고 Pages 를 켜면 됩니다. 자산 경로는 모두 상대 경로라 저장소 이름·하위 경로가 바뀌어도 동작합니다.
「첫 화면으로」 버튼은 이 웹제안서의 첫 화면(`#hero`)으로 이동합니다. 현재 상위 폴더에는 별도의 안내 페이지(`../index.html`)가 없으므로 존재하지 않는 파일을 가리키지 않습니다.

웹 폰트(Pretendard)만 `cdn.jsdelivr.net` 에서 불러옵니다. 차단된 망에서도 시스템 글꼴로 정상 표시됩니다.

## 공개 범위 주의

GitHub Pages 는 저장소가 Private 이어도 무료 플랜에서 **페이지가 공개**됩니다.
`noindex` 로 검색 노출은 막았지만 **주소를 아는 사람은 누구나 열 수 있습니다.**
이 페이지에는 **제안 금액 · MD 단가 · 인력 참여율 · 기능별 견적**이 들어 있으므로 **발주처 담당자에게만** 전달해 주십시오.
`제안서.md` · `verify*.py` 는 공개 대상이 아니므로 저장소에 올릴 때 `.gitignore` 로 제외하십시오.
