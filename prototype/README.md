# 시멘트 통계 포털 — 프로토타입 (위시켓 158558)

제안서(`../제안서.md`)의 §7 개발 범위를 화면과 상호작용으로 구현한 브라우저 프로토타입입니다.
회원사 웹 12화면 + 협회 관리자 웹 15화면 = **27화면**(제안서 §7-13)을 담았습니다.

## 여는 방법

`index.html`을 브라우저에서 바로 열면 됩니다. 빌드도 서버도 필요 없습니다. 처음에는 로그인 화면이 열립니다.
GitHub Pages 에 올릴 때는 이 폴더를 그대로 배포합니다 (`.nojekyll` 포함). 자산 경로는 모두 상대 경로입니다.

## 체험 계정

로그인 화면에서 업무 영역을 **회원사** 또는 **협회**로 선택하면 해당 영역의 체험 계정만 표시됩니다. 계정을 누르면 이메일·비밀번호가 입력됩니다. **로그인**을 누르면 해당 역할의 업무 화면으로 이동합니다. 다른 역할을 보려면 우측 상단 계정 메뉴에서 로그아웃한 뒤 다시 로그인하세요.

| 업무 영역 | 이메일 | 비밀번호 | 사용 예 |
| --- | --- | --- | --- |
| 회원사 관리자 | `member@demo.cement` | `member2026` | 입력·제출·직원 권한 관리 |
| 회원사 직원 | `staff@demo.cement` | `staff2026` | 자료 입력·조회 |
| 협회 관리자 | `admin@demo.cement` | `admin2026` | 제출 검증·확정·통계 |
| 협회 통계 담당 | `stat@demo.cement` | `stat2026` | 통계·보고서·외부 수집 |
| 다른 회원사 9곳 | `member01@demo.cement` ~ `member10@demo.cement` 중 해당 회사 번호 (`04` 제외) | `member2026` | 회원사별 제출 흐름과 자료 분리 확인 |

## 화면 구성 (27)

**회원사 웹 12** — 로그인 / 요약 대시보드 / 대량 입력표 / 엑셀 업로드·일괄 등록 / 속보 입력 / 유연탄 입력 / 수출입 입력 /
제출·보완 요청 현황 / 통계 조회·다운로드 / 전년 동기 비교 조회 / 지도 대시보드 / 계정·직원 권한 관리

**협회 관리자 웹 15** — 로그인 / 운영 대시보드 / 회원사별 제출 현황판 / 검증 결과·예외 처리 / 확정·마감 처리 / 정정 이력 /
통계 조회·보고서 출력 / 맞춤 보고서 만들기 / 지도 대시보드(전체) / 기준정보 관리 / 사용자 계정·권한 관리 /
외부 데이터 수집·검수 / 이관 검증 결과 조회 / 감사 로그 조회 / 알림 이력

로그인과 두 대시보드에는 시멘트 공장 사진을, 자료 업로드와 회원사 제출 현황에는 각각 시험실·출하 현장 사진을 배치했습니다. 사진은 화면용으로 생성한 이미지이며 실제 회원사 시설을 촬영한 자료가 아닙니다.

## 이 프로토타입이 실제로 계산하는 것

- **단일 집계 서비스** — 표·내려받기·보고서·지도·대시보드가 모두 `DB.aggregate()` 하나만 부릅니다. 결과에 지문(#)이 붙어 경로가 달라도 같은 조건이면 같은 값임을 보여 줍니다.
- **발행 버전 스냅샷** — 마감하면 v1이 만들어지고, 정정이 승인되면 v1을 지우지 않고 v2를 발행합니다. 보고서는 버전을 골라 보존본으로 다시 출력할 수 있습니다.
- **검증 3지점** — 입력(필수값·정수·음수·급변 경고) · 제출(재고 수지 · 지역 상세 합계 ↔ 내수 출하 총괄 · 기초재고 = 전월 확정 기말) · 확정(급변 경고 협회 확인).
- **상태 머신** — 작성 중 → 제출 → (보완 요청 → 작성 중) → 확정 → 마감. 허용되지 않은 전이와 역할이 맞지 않는 요청은 거절됩니다.
- **회원사 격리** — 회원사 세션이면 조회 대상 회원사를 서버 역할 코드가 덮어씁니다. 다른 회원사를 요청하면 403과 감사 로그.
- **소수 지역 보호** — 시·도와 시·군·구 단위 모두, 구성 회원사 3개사 미만 칸을 비공개하고, 비공개 칸이 하나뿐이거나 비공개 칸들의 회원사 합집합이 3개사 미만이면 다음으로 작은 칸도 비공개합니다.
- **업로드** — Excel(.xlsx)과 CSV(UTF-8)를 읽습니다. 여러 시트가 있으면 올릴 시트를 선택합니다. 머리글로 양식을 판별하고 전 행을 검증한 뒤, 오류가 하나라도 있으면 아무것도 반영하지 않습니다. 업로드 미리보기와 기록은 회원사별로 나뉘며, 반영 직전에 권한·작성 상태·파일을 다시 검사합니다.
- **기준정보 이력** — 합병(2023-01, (구) 동진양회 → 라온산업)과 폐쇄(2025-06, 장성2공장) 전후가 집계에서 구분됩니다.

## 알아 두실 점

- 모든 회사명·공장·인물·수치는 **시연용 가상 데이터**입니다. 실제 회원사와 관계가 없습니다.
- 변경한 체험 데이터와 로그인 상태는 **현재 브라우저의 로컬 저장소에만** 보관되므로 새로고침 후에도 유지됩니다. 서버·다른 브라우저와 동기화되지 않으며, 저장 공간이나 브라우저 설정 때문에 보관할 수 없으면 화면에 알림이 나옵니다. 로그인 화면의 「체험 데이터 초기화」를 누르면 이 프로젝트의 저장 데이터만 삭제하고 처음 상태로 돌아갑니다.
- 로그인은 브라우저 안에서만 동작하는 체험 계정입니다. 실서버 인증·메일 발송·외부 수집 API 호출은 없습니다. 알림 이력은 시연용으로만 기록하며 실제 이메일을 보내지 않습니다.
- 화면의 「마감·발행」은 모든 회원사 자료가 확정된 뒤에만 사용할 수 있습니다. 미제출 회원사 자료를 임의로 채우는 기능은 제공하지 않습니다.
- 업로드는 브라우저에 포함한 SheetJS 0.20.3으로 `.xlsx` 파일을 직접 읽고, CSV(UTF-8)도 지원합니다. 양식·오류 목록·통계 등의 내려받기는 CSV입니다. 실제 서버 구현의 엑셀 처리 방식은 제안서 §6을 따릅니다.
- 급변 경고 기준(전월 ±30%, 전년 동월 ±40%, 차이 800톤 이상)과 비공개 임계값(3개사)은 시연용 설정값입니다. 실제 값은 S1에서 협회와 확정합니다(제안서 §3-3 3번).
- 시·도 경계는 "Map of South Korea" by Victor Cazanave (svg-maps, **CC BY 4.0**)의 좌표를 사용했습니다. 시·군·구 확대 화면은 타일 배치이며, 실제 구현은 공공 행정구역 경계 데이터를 씁니다.
- 웹 폰트(Pretendard)만 `cdn.jsdelivr.net` 에서 불러옵니다. 차단된 망에서도 시스템 글꼴로 정상 표시됩니다.

## 공개 범위

GitHub Pages 는 저장소가 Private 이어도 무료 플랜에서 페이지가 공개됩니다. 모든 페이지에 `noindex` 를 넣었지만 주소를 아는 사람은 누구나 열 수 있으므로 발주처 담당자에게만 전달해 주십시오.

## 개발 메모

- 정적 HTML · CSS · JavaScript. 해시 라우터 + 이벤트 위임. 엑셀 읽기만 로컬에 포함한 SheetJS 라이브러리를 사용합니다.
- SheetJS Community Edition 0.20.3의 저작권·라이선스 고지는 `assets/vendor/NOTICE.md`, Apache 2.0 전문은 `assets/vendor/LICENSE-APACHE-2.0.txt`에 포함했습니다.
- `assets/geo.js` 행정구역 · `assets/data.js` 도메인 엔진과 시드 · `assets/ui.js` 셸·차트·지도 · `assets/common.js` 화면 공통 부품 · `assets/member.js` 회원사 12화면 · `assets/admin.js` 협회 15화면.
- `t_check.js`는 기존 Playwright 검증 스크립트입니다. 현재 로그인·화면 흐름 변경에 맞춘 재검증이 필요하며 배포물에는 포함하지 않아도 됩니다.
